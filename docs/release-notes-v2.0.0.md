# 启幕 v2.0.0

**界面全面改版：Material Design 3 → 瑞士国际主义风格（Swiss / International Typographic Style）。**

这是一次破坏性的视觉变更，因此升主版本号。功能与 v1.4.0 一致（开机/关机动画、双端制作与刷入、取用区间、取消、预览），本版只改视觉与交互质感。

---

## 1. 设计语言

| 维度 | v1.4.0（MD3 深色） | v2.0.0（瑞士风） |
|---|---|---|
| 配色 | 深藏青 + 20 余色 | **三色平涂**：黑 `#1A1A1A` / 米白 `#F5F2ED` / 强调红 `#DA291C` |
| 圆角 | 55 处 | **全部 0**（按钮保留小圆角以表达可点性） |
| 阴影 | 13 处 + 四级高度 | **全部移除**，层级改由 1px 细线承担 |
| 渐变 | 9 处 | 装饰性 **5 处删除**；功能性 3 处保留（进度条/刻度/滑杆） |
| 对齐 | 5 处居中 | **一律左对齐**（编号圆点等功能性元素除外） |
| 字体 | Segoe UI | **Inter 优先 + 雅黑兑中** |
| 字重 | 400/500/600/700 混用 | **统一体系**：正文 `--fw-body`、强调 700 |
| 区块标识 | 无 | **01–08 编号 + 小号大写标签** |
| 间距 | 4px 基数 | **8px 基数**，12 栏网格 |

**层级只靠透明度、间距、字号、线宽表达，不引入第二强调色** —— 状态色（成功/警告/错误）也受三色约束，靠透明度区分强度。

## 2. 动效

运动系统分两条曲线，各司其职：

| 曲线 | 值 | 用途 |
|---|---|---|
| `--ease-elastic` | `cubic-bezier(.34, 1.56, .64, 1)` | **仅形变**（transform/scale）—— overshoot 提供重量感 |
| `--ease-emphasized` | `cubic-bezier(.2, 0, 0, 1)` | 颜色/透明度/视图转场 —— 无 overshoot |

**为什么弹性曲线不用于视图转场**：弹性会 overshoot，整屏视图切换会来回抖。弹性只服务于细节。

时长：微交互 90–180ms，面板 320ms，复杂过渡 480ms，全部在规范区间内。`prefers-reduced-motion` 完整保留。

修复前实测：10 处形变过渡中只有 3 处用弹性曲线，`.btn`（按钮）、`.check .box`、`.opt .tick`、`.tip` 仍是标准曲线 —— 这正是"交互缺重量感"的原因。现已 **10/10**。

## 3. 图标

- 应用图标与品牌标记**统一为同一几何**（此前两者形状不一致）
- 缺口由**朝上改为朝下**：原几何"缺口朝上 + 中心点"看起来是一张脸，改为缺口朝下后读作"升起的拱"
- 图标几何用精确光栅化 + 无头浏览器**双路对照**验证（结果一致）

## 4. 安卓端同步

| 项 | 改动 |
|---|---|
| 颜色 | 35 个色值统一指向新增的共享 `Palette` |
| 圆角 | 卡片/弹窗 → 0；按钮保留 11dp |
| 字重 | 正文 → BOLD |
| `colors.xml` | 重写为三色，**删除 11 个死资源**（`md_space_*`、`md_shape_*`、`md_ripple`，实测零引用） |
| `styles.xml` | `windowBackground` 纠正为米白 —— 否则启动瞬间会闪深色背景 |

**顺带消除重复逻辑**：`MainActivity` 与 `CreatorActivity` 原先**各自重复定义**同一套 20/15 个颜色常量。现收敛为 `Palette` 单一来源，保留原常量名作别名，38 处调用点零改动。

## 5. 修复的缺陷

- **R1**：`creatortest-android.js` 从 `.work/` 读测试装置，而 `.work` 会被清理 → 测试整体失效。已把测试装置**内联进脚本**（与 `coretest-android.js` 同一模式），不再依赖临时目录。
- **R2**：`coretest` 因测试素材缺失静默少跑 6 项断言。补回后 31/31。
- 版本号一致性：`package.json` 2.0.0 = Manifest `versionCode 200` / `versionName 2.0.0`。

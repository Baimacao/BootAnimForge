# 启幕 v2.0.2

修复 PC 端图标。**安卓端功能无改动**，本版主要是把图标整体换成官方图标集。

---

## 问题：右上角图标很奇怪

反馈很准确。实测发现**两个图标路径本身就是坏的数据**：

| 图标 | 问题 |
|---|---|
| 「切换明暗主题」 | 路径画出来的**不是太阳**，而是一个歪扭的锯齿星形 —— 该路径缺少规范尖角星形的对称性 |
| 「退出程序」的 × | 手改过的叉号，**左右不对称**（4.6/6.4 与 6.4/4.6 的镜像关系错位） |

更根本的问题是**两套图标体系混用**：一部分是标准 Material 形状，一部分是手改过的路径，视觉重量不统一。

## 修法：整体换成官方 Material Symbols Outlined

按你的建议采用官方图标库。数据来自 npm 包 `@material-symbols/svg-400`（**官方** Material Symbols，outlined 变体），
只提取 path 数据**内嵌进 HTML** —— 项目仍是**零运行时依赖**。

**30 个通用图标全部替换**，覆盖：appbar、卡片标题、特性格、拖放区、欢迎页、完成页、消息提示。

| 位置 | 图标 |
|---|---|
| 右上角 | `help`（教程）、`close`（退出） |
| 卡片 | `desktop_windows`、`crop_free`、`schedule`、`sync_alt`、`grid_view`、`movie_edit`、`folder`、`view_column`、`movie` |
| 操作 | `split`、`play_arrow`、`chevron_right`、`check`、`upload`、`layers` |
| 状态 | `info`、`warning`、`check_circle`、`verified_user`、`power_settings_new` |

**保留品牌 logo 不动** —— 它是「启幕」的标识，必须与安卓应用图标同形，不属于通用图标体系。

## 顺带移除了一个失效功能

「切换明暗主题」按钮**实际已经无效**：`applyTheme()` 会设置 `data-theme` 属性，
但瑞士风格改成单主题后，CSS 里的 `:root[data-theme="light"]` 规则已被删除（实测 grep 为零），
所以点击它**没有任何视觉变化**。

已连同按钮、`applyTheme()`、`state.theme` 持久化一并删除 —— 而不是留一个无效果的控件。

**旧的坏路径不得再出现**（锯齿星形与不对称叉号各一条）。
